# @missionhud/appspec-provenance

W3C PROV-shaped provenance envelope helpers for AppSpec v10 nodes. Every entity (Project, Screen, ComponentInstance, AssetRef, Flow, FlowStep) carries a `_provenance` envelope; these helpers keep it well-formed.

## Install

```bash
npm install @missionhud/appspec-provenance
```

## Use

```js
const {
  createProvenance,
  touchProvenance,
  generateId,
  setExternalId,
  markTombstone,
  resolveTombstone,
  VALID_SOURCES,
} = require('@missionhud/appspec-provenance');

// Create a fresh provenance envelope for a new node
const prov = createProvenance({
  source: 'human-edit',
  note: 'Initial creation',
});

// Update on edit — appends a sourceTimeline entry, bumps lastEditedAt
touchProvenance(prov, {
  source: 'mockingbird-ai',
  note: 'AI tightened copy',
});

// Generate ids
const projectId = generateId('proj');     // → "proj_a1b2c3d4e5f6"
const screenId  = generateId('screen');   // → "screen_..."
const compId    = generateId('comp');     // → "comp_..."

// Track external system ids (figma node id, MHB id)
setExternalId(prov, 'figma', '1234:5678');

// Soft-delete a node that disappeared from its source
markTombstone(prov, { removedFrom: 'figma', lastSeenAt: '2026-05-01T00:00:00Z' });

// Resolve human decision
resolveTombstone(prov, 'delete', 'Designer confirmed removal');
```

## Valid source values

`createProvenance` and `touchProvenance` throw if `source` isn't one of:

| Source | Meaning |
|---|---|
| `human-edit` | User-driven mutation in a producer UI |
| `figma-import` | Extracted from a Figma file |
| `mhb-push` | Proposed/applied by Mission HUD Builder |
| `mockingbird-ai` | Generated by Mission HUD Designer's orchestrator (legacy name retained for back-compat with pre-rename specs; a future v11 will deprecate in favour of `designer-ai`) |
| `preset-load` | Loaded from a curated preset |
| `unknown` | Legacy / migrated, source not recorded |

## Why "mockingbird-ai" is still in the enum

The package was renamed from Mockingbird to Mission HUD Designer in May 2026. Specs generated before the rename carry `mockingbird-ai` in their `sourceTimeline`. Removing the enum value would break Forever Backwards Read (see [GOVERNANCE.md § 3](https://github.com/missionhud/appspec/blob/main/GOVERNANCE.md#3-versioning)). A future v11 major version will deprecate it in favour of `designer-ai`.
